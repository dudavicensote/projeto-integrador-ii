# TaskFlow - Projeto Integrador Transdisciplinar em Engenharia de Software II

Aplicação web desenvolvida em arquitetura **MVC (Model-View-Controller)** utilizando **HTML5, CSS3, JavaScript (Node.js/Express)** e banco de dados relacional **SQLite**.

## Como executar o projeto localmente
1. Instale as dependências: `npm install`
2. Execute os testes: `npm test`
3. Inicie o servidor: `npm start`
4. Acesse no navegador: `http://localhost:3000`
